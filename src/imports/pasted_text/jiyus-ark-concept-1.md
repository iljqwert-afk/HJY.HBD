# ⭐ 그리고 아주 중요한 디테일

각 미니게임을 따로 노는 게임처럼 만들지 말고 **하나의 방주 상태가 계속 이어지게** 하는 게 좋아.

예를 들어 상단에 항상:

```text
🚢 ARK STATUS

STRUCTURE  ██████████ 100%
LIGHT      ████████░░  80%
SUPPLIES   ██████░░░░  60%
HOPE       ██████████ 100%
```

이런 HUD를 두는 것.

미니게임 1을 클리어하면 **STRUCTURE**가 올라가고,

미니게임 2에서 촛불을 지키면 **LIGHT**가 올라가고,

미니게임 3에서 불안을 내려놓으면 **HOPE**가 올라가고,

미니게임 4를 끝내면 모든 게 100%가 된다.

그러면 사용자는 단순히 미니게임 4개를 깨는 게 아니라 **“지유의 방주를 완성해가는 느낌”**을 받게 돼.

그리고 마지막 화면에서:

```text
╭──────────────────────────╮
│       ARK COMPLETE       │
│                          │
│  FAITH       █████ 100%  │
│  HOPE        █████ 100%  │
│  LOVE        █████ 100%  │
│  LIGHT       █████ 100%  │
│                          │
│       JOURNEY END        │
╰──────────────────────────╯
```

로 끝내면 꽤 완성도 높은 **기독교적 생일 인터랙티브 웹게임**이 될 거야.
